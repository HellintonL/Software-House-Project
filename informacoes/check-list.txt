LISTA DE TAREFAS DO PROJETO
============================

Marque uma tarefa com [x] quando ela estiver pronta.
Deixe [ ] nas tarefas que ainda precisam ser feitas.
Siga a ordem da lista para construir o projeto passo a passo.

1. ORGANIZAR O PROJETO

[ ] 1.1 Conferir se os nomes das informações são iguais em todas as páginas.
[ ] 1.2 Decidir quais informações serão guardadas em cada arquivo de dados.
[ ] 1.3 Conferir se os arquivos de dados existem e estão vazios ou prontos para receber informações.
[ ] 1.4 Corrigir os endereços dos arquivos de aparência das páginas.
[ ] 1.5 Conferir se cada página está usando o arquivo de aparência correto.

2. FAZER O CLIENTE ENVIAR UM PROJETO

[ ] 2.1 Fazer o formulário de projeto-cliente.php receber o nome, o CPF, o tema e a descrição.
[ ] 2.2 Conferir se cada informação preenchida tem o nome correto para ser salva.
[ ] 2.3 Fazer essa página usar o arquivo dados/projetos.json.
[ ] 2.4 Salvar o projeto preenchido no arquivo dados/projetos.json.
[ ] 2.5 Guardar também a data em que o projeto foi enviado.
[ ] 2.6 Mostrar uma mensagem dizendo que o projeto foi enviado.

3. MOSTRAR OS PROJETOS PARA A EQUIPE

[ ] 3.1 Fazer os projetos enviados aparecerem na página da equipe de T.I.
[ ] 3.2 Mostrar o nome, o e-mail e a descrição de cada projeto.
[ ] 3.3 Mostrar uma mensagem quando ainda não houver projetos para avaliar.
[ ] 3.4 Mostrar uma mensagem quando ainda não houver projetos respondidos.

4. FAZER A EQUIPE RESPONDER AOS PROJETOS

[ ] 4.1 Fazer a opção “aprovar” mudar a situação do projeto.
[ ] 4.2 Fazer a aprovação guardar o valor do orçamento.
[ ] 4.3 Permitir que a equipe informe o prazo do projeto.
[ ] 4.4 Fazer a opção “reprovar” mudar a situação do projeto.
[ ] 4.5 Conferir se os projetos aprovados aparecem na lista de projetos respondidos.
[ ] 4.6 Conferir se os projetos reprovados aparecem na lista de projetos respondidos.

5. PERMITIR QUE O CLIENTE CONSULTE O PROJETO

[ ] 5.1 Corrigir o endereço do arquivo que guarda os projetos.
[ ] 5.2 Permitir que o cliente procure seu projeto usando o e-mail.
[ ] 5.3 Mostrar o nome do projeto encontrado.
[ ] 5.4 Mostrar a descrição do projeto encontrado.
[ ] 5.5 Mostrar a situação atual do projeto.
[ ] 5.6 Mostrar o orçamento quando o projeto for aprovado.
[ ] 5.7 Mostrar o prazo quando o projeto for aprovado.
[ ] 5.8 Mostrar uma mensagem quando nenhum projeto for encontrado.
[ ] 5.9 Conferir se a resposta da equipe aparece corretamente para o cliente.

6. PERMITIR EXCLUIR PROJETOS

[ ] 6.1 Permitir que a equipe exclua apenas um projeto.
[ ] 6.2 Permitir que a equipe exclua todos os projetos.
[ ] 6.3 Conferir se um projeto excluído desaparece da lista da equipe.
[ ] 6.4 Conferir se um projeto excluído também desaparece da consulta do cliente.

7. CONFERIR AS FUNÇÕES PRINCIPAIS DO PROJETO

[ ] 7.1 Criar: enviar um projeto e guardar suas informações.
[ ] 7.2 Consultar: mostrar os projetos que foram guardados.
[ ] 7.3 Alterar: mudar a situação, o orçamento e o prazo do projeto.
[ ] 7.4 Excluir: apagar um projeto.
[ ] 7.5 Excluir todos: apagar todos os projetos guardados.

8. FAZER O CADASTRO FUNCIONAR

[ ] 8.1 Fazer o formulário de cadastro.php receber as informações preenchidas.
[ ] 8.2 Conferir se a página de cadastro está ligada aos arquivos corretos.
[ ] 8.3 Guardar os dados preenchidos no arquivo dados/cadastro.json.
[ ] 8.4 Mostrar na tela os cadastros que foram guardados.

9. FAZER O CADASTRO DE EMPRESAS FUNCIONAR

[ ] 9.1 Corrigir o endereço do arquivo dados/empresas.json.
[ ] 9.2 Conferir se as informações da empresa estão sendo guardadas corretamente.
[ ] 9.3 Corrigir a exibição do e-mail da empresa.
[ ] 9.4 Mostrar corretamente na tela as empresas cadastradas.

10. CORRIGIR OS LINKS E AS PÁGINAS

[ ] 10.1 Criar a página que será aberta pelo link “Ver orçamento e prazo”.
[ ] 10.2 Colocar o endereço correto no link do LinkedIn.
[ ] 10.3 Corrigir os links antigos do arquivo menu.html.
[ ] 10.4 Corrigir os links antigos da página cadastro.php.
[ ] 10.5 Conferir se todas as páginas estão mostrando seu estilo visual corretamente.

11. FAZER A CONFERÊNCIA FINAL

[ ] 11.1 Enviar um novo projeto pelo formulário.
[ ] 11.2 Conferir se o projeto aparece para a equipe de T.I.
[ ] 11.3 Aprovar um projeto e informar o orçamento.
[ ] 11.4 Reprovar um projeto.
[ ] 11.5 Consultar um projeto usando o e-mail.
[ ] 11.6 Conferir se o orçamento e o prazo aparecem para o cliente.
[ ] 11.7 Excluir apenas um projeto.
[ ] 11.8 Excluir todos os projetos.
[ ] 11.9 Fazer um cadastro e conferir se ele aparece na tela.
[ ] 11.10 Clicar nos principais links do site e conferir se todos funcionam.
[ ] 11.11 Conferir se as informações continuam guardadas corretamente nos arquivos de dados.
